# LoRA Captioner — текущий функционал

## Backend API

- **Health check** — `GET /api/health`
- **Список изображений** — `GET /api/dataset/items` с пагинацией, фильтром «только пустые», поиском по имени файла и капшену
- **Статистика датасета** — `GET /api/dataset/stats` (total, tagged, untagged)
- **Сохранение капшена** — `PUT /api/dataset/caption` (создаёт/обновляет `.txt`-файл, удаляет если пусто)
- **Загрузка папки** — `POST /api/dataset/upload-folder` (multipart, чанками по 20 файлов)
- **Batch-операции** — `POST /api/dataset/batch` (prepend/append/remove_tag/regex_replace, опционально только для untagged)
- **Рескан датасета** — `POST /api/dataset/rescan`
- **WebP-превью** — `GET /api/images/thumb/{filename}` (libvips + PIL fallback, дисковый кэш, инвалидация по mtime)
- **Полное изображение** — `GET /api/images/full/{filename}`
- **Конфигурация** — через `CAPTIONER_*` переменные окружения (путь к датасету, кэш превью, размер превью)
- **CORS** — разрешён для всех источников

## Frontend UI

- **Верхняя панель** — название/версия, статистика (total/tagged/untagged), сегментированный прогресс-бар, загрузка папки с индикатором прогресса, кнопка рескана
- **Тулбар** — поиск по имени/капшену, фильтр «только пустые», кнопка Batch-панели, кнопка открытия редактора (мобильные)
- **Сетка изображений** — виртуализированная (TanStack Virtual), адаптивное кол-во колонок, WebP-превью с lazy loading, мультивыбор через Ctrl+Click
- **Карточка изображения** — превью, имя файла, первые 2 строки капшена, цветная точка (tagged/untagged), номер кадра, циановая обводка/галочка при мульти-выборе
- **Редактор капшена** — зуммируемый/панарамируемый просмотр полноразмерного изображения (react-zoom-pan-pinch), режим тегов (добавление по Enter, удаление по X, drag-and-drop сортировка через dnd-kit), режим текстового поля, кнопка сохранить, индикатор dirty (оранжевая пульсация), навигация ← →
- **Batch-редактор (мультивыбор)** — отображение общих тегов для всех выделенных, селектор режима «В конец / В начало / Заменить», сохранение для всех выделенных
- **Batch-панель** — выбор операции (prepend/append/remove_tag/regex_replace), ввод значений, галочка «только пустые», кнопка «Применить»
- **Статус-бар** — количество кадров, активные фильтры/поиск, подсказки по хоткеям
- **Адаптивность** — на мобильных EditorPanel как оверлей, резиновая ширина сайдбара (80/96/440), колонки сетки от 1 до N, адаптивная шапка и тулбар
- **Уведомления** — toast-уведомления о сохранении/загрузке/ошибках (sonner)
- **Тёмная тема** — кастомная палитра (coal, paper, safe/cyano/ember), плёнка зернистости, виньетка
- **Горячие клавиши** — `⌘S` / `Ctrl+S` сохранить, `←` / `→` навигация по кадрам
- **Крупный шрифт** — `text-xs` = 14px, `text-sm` = 16px (кастомная шкала Tailwind)

## Инфраструктура / Docker

- **Docker Compose** — сервисы `backend` (FastAPI :8000) и `frontend` (Nginx :8080)
- **Backend Dockerfile** — python:3.12-slim + libvips + build-essential
- **Frontend Dockerfile** — мультистейдж: node:20 сборка → nginx:1.27-alpine
- **Nginx** — прокси `/api/*` на backend, SPA fallback, unlimited client body size, таймауты 300s
- **Volume** — `thumb_cache` для кэша превью
- **Bind mount** — папка датасета монтируется в `/data/dataset`
- **Health check** — curl к `/api/health` (интервал 10s, start period 10s)
- **restart: unless-stopped** — авто-восстановление контейнеров
